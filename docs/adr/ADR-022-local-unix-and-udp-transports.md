# ADR-022. Локальные Unix-domain и UDP транспорты

25.10.2026, PROPOSED. Продолжение максимальной Memcached-совместимости, не смена cache engine.

- `listen.unixSocket` — optional абсолютный путь нового сокета, вместо TCP listener. Существующий путь не удаляется/перезаписывается. Используется JDK UNIX ServerSocketChannel и тот же NIO handler/budgets; Unix endpoint и TCP port не обслуживаются одновременно. Автоматического unlink нет: проверка fileKey затем delete не атомарна и может удалить подменённый путь. Оператор управляет приватным каталогом и удалением оставшегося socket entry после остановки; сервер никогда не удаляет этот путь. Это явное эксплуатационное отличие ради сохранности файлов. Windows/другая платформа без поддержки должна fail-closed, квалификация на имеющемся Linux WSL отдельная.
- `listen.udpPort` — optional порт, выключен при отсутствии. Только numeric loopback; внешний UDP запрещён до отдельного проектирования anti-amplification/ACL. Authentication/TLS+UDP запрещены (UDP не превращается в обход защищённого TCP). Локальный UDP не является защищённым транспортом.
- UDP header8байт: request-id/sequence/total/reserved network order. Request total=1 поддерживается, sequence/reserved игнорируются как у pinned1.6.45; multi-packet input молча отбрасывается, не собирается в неограниченные буферы. Полнота всех кадров внутри датаграммы проверяется до admission/изменения кеша. Ответы фрагментируются в датаграммы с тем же id и последовательностью, bounded maximum output bytes/packets; превышение возвращает определённую ошибку, не частичный успешный поток.
- Один фиксированный UDP worker, bounded request/response budget и reuse текущего engine/codec; никаких per-peer maps/threads и retained values между datagrams. Binary UDP допускается только при подтверждённом reference поведении, иначе явно ограничить ASCII/meta. Результаты и leases закрываются при каждом packet/disconnect/failure/shutdown.
- Уточнение реализации: binary UDP подтверждён pinned oracle. UDP worker заранее резервирует `1048576 + 65536 + 1400 + 262144 + 10816 + factory.additionalControlBytes()` байт фиксированного графа, включая bounded preflight/transient запас; packet body и line используют те же глобальные пулы, что NIO. `resourceUsage.controlBytes` включает UDP allowance; fixed charge возвращается после worker termination. Дополнительный writer добавляет один epoch в startup allowance. Unexpected receive/send failure останавливает общий lifecycle, не оставляет молча мёртвый endpoint. Response cap —1MiB: binary получает typed status0x82 с opaque/opcode, ASCII — SERVER_ERROR; ограничение не называется поведением неограниченного эталона.
- Независимые probes: shared cache TCP↔UNIX/UDP, binary/text/meta там где применимо, header endianness/id/fragmentation, malformed multi-packet requests, noreply, oversized output bounds, startup conflicts/security denied, shutdown cleanup. Не переносить TCP PASS на новые транспорты.
