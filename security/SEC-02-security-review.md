# SEC-02. Независимая проверка безопасности

**Цель.** Провести независимую проверку безопасности кандидата в выпуск.

**Зависит от.** T-015, SEC-01.

**Входы.** [tests/TEST-07](../tests/TEST-07-security.md), [docs/07](../docs/07-security-operations-release.md), SEC-01.

**Результаты.**
- Отчёт независимой проверки по модели угроз.
- Классификация найденных дефектов по приоритету.
- Перечень остаточных рисков и ограничений.

**Критерии приёмки.**
1. Проверка выполнена агентом, не участвовавшим в реализации.
2. Открытых критических и высоких дефектов нет.
3. Каждый остаточный риск имеет владельца и ограничение применимости.
4. Отчёт не завышает гарантии и содержит ограничения продукта.

**Проверка.** Просмотр отчёта ведущим, выборочная повторная проверка находок.

**Роли.** Исполнитель — сильный; контролёр — сильный.

**Вне области.** Устранение дефектов и принятие риска (решение человека).

**Ограничения.** Принятие риска безопасности — только человек.

**Бюджет.** Оценивается координатором по объёму и доступным проверкам; локального манифеста процесса нет.
