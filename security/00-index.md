# security: работы по безопасности octomem

Версия 0.1 от 14.09.2026.

Каталог `security` содержит работы по безопасности продукта: модель угроз, независимые проверки, безопасность зависимостей, доступы и секреты. Он дополняет [docs/07](../docs/07-security-operations-release.md) (модель угроз и требования) и [tests/TEST-07](../tests/TEST-07-security.md) (испытания безопасности).

## Правила

1. Безопасность не расширяет и не сужает продуктовые требования; она проверяет их выполнение и выявляет риски.
2. Никакие изменения из этого каталога не ослабляют критерии приёмки; риск принимается только решением человека по [границам разрешений](../docs/development.md).
3. Продукт остаётся сетевым кешем и не заявляется средством защиты; это ограничение фиксируется во всех отчётах.
4. Найденные уязвимости получают приоритет, владельца и срок по [docs/07](../docs/07-security-operations-release.md).
