# SEC-03. Безопасность зависимостей и лицензий

**Цель.** Подтвердить состав зависимостей, их лицензии и отсутствие известных уязвимостей.

**Зависит от.** T-015.

**Входы.** `SBOM` поставки, [docs/07](../docs/07-security-operations-release.md), [docs/ref-registry-research.md](../docs/ref-registry-research.md).

**Результаты.**
- Перечень runtime и тестовых зависимостей с лицензиями.
- Проверка известных уязвимостей на зафиксированных версиях.
- Подтверждение отсутствия обязательных платных runtime-компонентов.

**Критерии приёмки.**
1. Все лицензии свободные и совместимы с распространением.
2. Известные уязвимости проверены; критических и высоких нет.
3. Сторонних Java/native runtime-библиотек нет; OpenJDK 25 указана как платформа, build/test-компоненты не упакованы.
4. `SBOM` соответствует фактической поставке.
5. Проверены полные лицензии и экспортные/территориальные условия точных сборок ОС/OpenJDK и инструментов по REG-02. Справочная таблица портала не заменяет проверку поставки; неизвестные условия не считаются разрешением.

**Проверка.** Сверка `SBOM` с содержимым артефактов, отчёт проверки уязвимостей.

**Роли.** Исполнитель — дешёвый; контролёр — сильный.

**Вне области.** Закупка лицензий и юридические решения.

**Ограничения.** Проверка опирается на доступные базы; отсутствие записи в базе не доказывает отсутствие уязвимости.

**Бюджет.** Оценивается координатором по объёму и доступным проверкам; локального манифеста процесса нет.
