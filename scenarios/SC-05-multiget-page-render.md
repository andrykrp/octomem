# SC-05. Multi-get для отрисовки страницы

**Контекст.** Приложение собирает страницу из множества фрагментов и запрашивает их одним обращением к кешу, чтобы снизить сетевые задержки.

**Участники.** Приложение, octomem.

**Поток.**
1. Приложение формирует список ключей фрагментов.
2. Одной командой запрашивает все значения.
3. Для ненайденных фрагментов обращается к источнику и заполняет кеш.
4. При необходимости получает версии для условного обновления.

**Команды.** `get` с несколькими ключами, `gets`, `gat`/`gats`.

**Что должно быть верно.**
- Ответ передаётся потоково и не материализуется целиком в памяти.
- Большой ответ не разрывает соединение для читающего клиента.
- При остановившемся читателе память не растёт сверх лимита.
- Повторяющиеся ключи не приводят к неопределённому поведению.
- Просроченные фрагменты не возвращаются.

**Связанные требования.** docs/03 §5, docs/04 §3, Т-01, Т-05.

**Открытые вопросы.** Типичная длина списка ключей и размер фрагментов.

**Границы.** Число ключей ограничено длиной строки команды; очень большие страницы собираются несколькими запросами.
