# SC-04. Локальный кеш микросервиса

**Контекст.** Микросервис кеширует справочные данные, полученные от другого сервиса, чтобы снизить задержки и число вызовов.

**Участники.** Микросервис, octomem, сервис-источник.

**Поток.**
1. Сервис получает конфигурацию или справочник у источника.
2. Сохраняет данные в кеш с разумным сроком жизни.
3. Читает данные из кеша до истечения срока.
4. По истечении обновляет данные.
5. При плановом обновлении справочника очищает кеш.

**Команды.** `get`, `set`, `touch`, `delete`, `flush_all`.

**Что должно быть верно.**
- Кеш переживает перезапуск сервиса, но не перезапуск octomem.
- Значения могут быть большими; учитывается предел записи.
- При недоступности кеша сервис деградирует, а не падает.

**Связанные требования.** docs/04, ЧТЗ-03, ЧТЗ-07.

**Открытые вопросы.** Нужен ли отдельный экземпляр кеша на сервис или общий.

**Границы.** Без диска и кластера; отказоустойчивость решается на уровне приложения.
