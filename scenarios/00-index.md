# scenarios: сценарии использования octomem

Версия 0.1 от 14.09.2026.

Каталог `scenarios` содержит возможные сценарии применения продукта. Они нужны, чтобы проверять требования на реальных задачах, а не только на синтетических тестах, и чтобы понимать, какие клиенты и команды критичны.

Сценарии не являются обязательствами и не входят в приёмку по умолчанию. Сценарий становится проверяемым, когда для него найден законный пилот и он попадает в [tests/TEST-02](../tests/TEST-02-integration.md).

## Сценарии

| ID | Сценарий | Основные команды |
|---|---|---|
| [SC-01](SC-01-web-session-cache.md) | Кеш веб-сессий | `set`, `get`, `touch`, `delete` |
| [SC-02](SC-02-db-query-cache.md) | Кеш результатов запросов к базе | `get`, `set`, `cas`, `delete` |
| [SC-03](SC-03-counter-rate-limit.md) | Счётчики и ограничение частоты | `incr`, `decr`, `add`, `touch` |
| [SC-04](SC-04-microservice-local-cache.md) | Локальный кеш микросервиса | `get`, `set`, `flush_all` |
| [SC-05](SC-05-multiget-page-render.md) | Multi-get для отрисовки страницы | `get` с несколькими ключами, `gets` |

## Правила

1. Сценарий описывает только использование, а не реализацию.
2. Если для сценария требуется изменить код приложения сверх адреса сервера, это фиксируется отдельно.
3. Сценарий не оправдывает выход за границы выпуска 1.0 (без диска, без кластера, без Redis).
4. Персональные данные в сценариях не используются.
