# SC-03. Счётчики и ограничение частоты

**Контекст.** Приложение ограничивает частоту обращений пользователя или клиента, считая запросы в окне времени.

**Участники.** Приложение, octomem.

**Поток.**
1. Приложение увеличивает счётчик по ключу пользователя.
2. Если ключа нет, счётчик создаётся со сроком жизни, равным окну.
3. При превышении порога запрос отклоняется.
4. По истечении срока счётчик исчезает, окно начинается заново.

**Команды.** `add`, `incr`, `touch`, `get`, `delete`.

**Что должно быть верно.**
- `incr` атомарен при конкурентных запросах.
- `decr` не уходит ниже нуля.
- Срок жизни счётчика задаётся корректно, включая границы 2 592 000 секунд.
- Отсутствие ключа обрабатывается корректно (`NOT_FOUND`).

**Связанные требования.** docs/04 §5.2, ЧТЗ-05.

**Открытые вопросы.** Нужны ли скользящие окна (реализуются приложением, не кешем).

**Границы.** Точное распределённое ограничение частоты требует отдельного решения; кеш даёт только атомарный счётчик.
