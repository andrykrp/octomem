# D-04. Структура справки и документации

**Цель.** Определить структуру встроенной справки и пользовательской документации.

**Зависит от.** D-01, D-02, D-03.

**Входы.** docs/02 §10, docs/04, D-02.

**Результаты.**
- Содержание и порядок разделов справки командной строки.
- Структура руководств: установка, конфигурация, эксплуатация, протокол, известные отличия, сборка.
- Правила русскоязычного оформления: кавычки, тире, единицы, числа.
- Соглашения об именах файлов документации.

**Критерии приёмки.**
1. Справка покрывает все команды и параметры.
2. Структура руководств позволяет выполнить установку и запуск без обращения к другим источникам.
3. Терминология совпадает с глоссарием docs/01.
4. Нет ссылок на несуществующие разделы.

**Проверка.** Ревью ведущим, пробный проход по структуре.

**Роли.** Исполнитель — дешёвый; контролёр — сильный.

**Вне области.** Написание самих руководств (T-016).

**Ограничения.** Структура не вводит новых продуктовых требований.
