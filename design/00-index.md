# design: задачи дизайна octomem

Версия 0.1 от 14.09.2026.

Задачи дизайна отвечают за то, как продукт выглядит и ощущается для человека: интерфейс командной строки, сообщения, схема конфигурации, структура справки и документации. Продуктовые требования при этом не меняются — они заданы в `docs/`.

| ID | Задача | Зависит от |
|---|---|---|
| [D-01](D-01-cli-ux.md) | Интерфейс командной строки | — |
| [D-02](D-02-config-schema.md) | Схема конфигурации | D-01 |
| [D-03](D-03-messages-and-exit-codes.md) | Сообщения и коды возврата | D-01 |
| [D-04](D-04-help-and-docs-structure.md) | Структура справки и документации | D-01, D-03 |

Правила дизайна:

1. Дизайн не меняет контракт протокола и набор настроек; он определяет форму их представления человеку.
2. Все тексты для пользователя — на русском языке; строки сетевого протокола остаются английскими по docs/04.
3. Дизайн считается принятым, когда задача T-002 и T-016 могут быть выполнены по нему без дополнительных вопросов.
