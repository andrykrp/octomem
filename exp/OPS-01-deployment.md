# OPS-01. Развёртывание и конфигурация на стенде

**Цель.** Описать и проверить установку octomem на чистом стенде.

**Зависит от.** T-015.

**Входы.** [docs/03 §8](../docs/03-architecture-specification.md), [tasks/T-002](../tasks/T-002-config-and-cli.md), поставка T-015.

**Результаты.**
- Инструкция установки: распаковка, права, каталоги, запуск.
- Базовый файл конфигурации для типового стенда.
- Проверка конфигурации до запуска.
- Список файлов, создаваемых сервером, и правила их очистки.
- Ограничение доступа: привязка к внутреннему интерфейсу, правила межсетевого экрана.

**Критерии приёмки.**
1. Установка на чистом стенде проходит по инструкции без административных прав.
2. Сервер принимает соединения и отдаёт `stats`.
3. Проверка конфигурации возвращает ненулевой код при ошибке.
4. Документированы все создаваемые файлы и их назначение.
5. Явно указано, что данные кеша теряются при перезапуске.

**Проверка.** Прогон на чистом стенде, снимок `stats`, проверка ошибок конфигурации.

**Роли.** Исполнитель — дешёвый; контролёр — сильный.

**Вне области.** Настройка основной базы и приложения.

**Ограничения.** Развёртывание в продуктивной среде выполняет человек.

**Бюджет.** Оценивается координатором по объёму и доступным проверкам; локального манифеста процесса нет.
