# TEST-07. Безопасность

**Категория.** Безопасность.

**Цель.** Подтвердить отсутствие опасных путей и сетевой изоляции.

**Метод.** Негативные и проверочные испытания по модели угроз docs/07.

**Зависит от.** T-006, T-013, T-015.
**Входы.** docs/06, docs/07.
**Результаты.** Отчёт безопасности, список ограничений, сведения о зависимостях.
**Вне области.** Пентест сторонних систем и изменение сетевой инфраструктуры.

**Минимум случаев.**
- Отсутствие исходящих сетевых соединений при работе.
- Привязка по умолчанию к локальному адресу.
- Огромные ключи, строки и значения не приводят к падению и утечке памяти.
- Специальные последовательности байтов и неверные блоки данных обрабатываются безопасно.
- Отсутствие чтения и записи файлов по запросу клиента.
- Отсутствие ключей и значений в журнале.
- Зависимости: лицензии свободные, известные уязвимости проверены.
- Пределы `protocol.maxLineBytes`, `item.maxSize`, `connections.pendingWriteBytes`, `connections.maxInflightCommands` не обходятся.

**Критерии приёмки.**
1. Нет путей, приводящих к исполнению кода, доступу к файлам или существенной утечке памяти.
2. Обязательные runtime-компоненты отсутствуют.
3. Открытых критических и высоких дефектов нет.

**Артефакты.** Отчёт безопасности, список ограничений, сведения о зависимостях.

**Роли.** Тестировщик — сильный.

**Ограничения.** Продукт не является средством защиты и не заменяет сетевую изоляцию.
