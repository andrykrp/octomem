# TEST-04. Функциональные испытания

**Категория.** Функциональные.

**Цель.** Проверить функции подсистем и служебные команды на реальном сервере.

**Метод.** Сценарные тесты поверх собранного сервера.

**Зависит от.** T-008, T-013.
**Входы.** docs/06, docs/04.
**Результаты.** Отчёт по тестам и сырые результаты.
**Вне области.** Нагрузочные и аварийные испытания.

**Минимум случаев.**
- Все методы `CacheEngine` и их результаты.
- Хранилище: коллизии, расширение, классы размеров, освобождение.
- Срок жизни: ленивое удаление, активная очистка, `touch`, `gat`.
- Вытеснение: порядок LRU, счётчики, поведение при нехватке памяти.
- `flush_all` с задержкой и без.
- `stats`: обязательные поля соответствуют реальным действиям.
- Конфигурация: приоритет источников, проверка без запуска, суффиксы размеров.

**Критерии приёмки.**
1. Все обязательные функциональные тесты `pass`.
2. Нет необъяснённых расхождений с ожидаемым поведением.
3. `stats` не искажает данные под нагрузкой.

**Артефакты.** Отчёт по тестам, сырые результаты.

**Роли.** Тестировщик — сильный.

**Ограничения.** Проверяет функции, но не заменяет нагрузочные и аварийные испытания.
