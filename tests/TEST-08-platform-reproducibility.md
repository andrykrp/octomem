# TEST-08. Платформы и воспроизводимость

**Категория.** Платформы и воспроизводимость.

**Цель.** Доказать работу на заявленных платформах и воспроизводимость поставки.

**Метод.** Один и тот же набор на каждой платформе; две автономные сборки из локального комплекта зависимостей на разных чистых стендах.

**Зависит от.** T-015.
**Входы.** docs/06, docs/07, docs/09.
**Результаты.** Матрица платформ, протокол сборки, хеши, результаты установки.
**Вне области.** Приобретение лицензий ОС и правовые решения по реестру.

**Минимум случаев.**
- Основная OpenJDK 25, байткод 25, точные patch-версии и SHA-256. 21 только отдельно вводимый резерв; Java 17 исключена.
- Основная ОС разработки.
- Две ОС с подтверждённым соответствием требованиям к доверенному ПО, точные версии/редакции/CPU и OpenJDK 25; документы REG-11 и законный доступ. Обычный Linux не заменяет эти доказательства.
- Установка, запуск, остановка, проверка конфигурации.
- Короткий функциональный и нагрузочный прогон.
- Поведение при перезапуске.
- Сборка с отключённой сетью; сравнение хешей полезной нагрузки двух сборок.
- Проверка контрольных сумм, `SBOM`, лицензии и `NOTICE`.
- Отсутствие сетевых загрузок во время работы.

**Критерии приёмки.**
1. Обязательные тесты `pass` на каждой заявленной платформе; непроверенная комбинация в заявленные не входит.
2. Полезная нагрузка двух сборок совпадает либо различия объяснены и не затрагивают код.
3. Все обязательные документы в поставке.
4. Отсутствие подходящей JDK 25 на выбранной ОС является блокером. Отдельно проверенный резерв 21 не подтверждает работу основной сборки 25 на этой ОС.

**Артефакты.** Матрица платформ, протокол сборки, хеши, результаты установки.

**Роли.** Тестировщик — сильный.

**Ограничения.** Класс продукта и применимость требования доверенных ОС уточняются до подачи в реестр.
