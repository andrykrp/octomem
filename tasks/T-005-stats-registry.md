# T-005. Счётчики и снимок статистики

**Цель.** Реализовать потокобезопасный реестр счётчиков и снимок статистики.

**Зависит от.** T-001.

**Входы.** docs/03 §4.5, ЧТЗ-06.

**Результаты.**
- `StatsRegistry` со счётчиками и показателями.
- Потокобезопасное увеличение и чтение.
- Снимок для команды `stats` и испытаний.
- Сброс счётчиков (`stats reset`) с сохранением неизменяемых значений.

**Критерии приёмки.**
1. Счётчики не теряют значения под нагрузкой.
2. Снимок пригоден для сравнения с эталоном.
3. Сброс не затрагивает неизменяемые поля.
4. Unit-тесты на границы и параллельный доступ.

**Проверка.** Unit-тесты, параллельный тест инкремента.

**Роли.** Исполнитель — дешёвый; контролёр — сильный.

**Вне области.** Вывод протокольных строк `STAT`.

**Ограничения.** Не вводить блокировку на каждое чтение счётчика.
