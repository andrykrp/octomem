# T-002. Конфигурация и командная строка

**Цель.** Реализовать разбор конфигурации, приоритет источников, проверку без запуска и базовый CLI.

**Зависит от.** T-001, D-01, D-02.

**Входы.** docs/03 §8 (полный набор ключей), ЧТЗ-07.

**Результаты.**
- Загрузка файла конфигурации и аргументов командной строки.
- Приоритет: аргументы > файл > значения по умолчанию.
- Проверка конфигурации без запуска сервера с понятными сообщениями.
- Печать версии и справки.
- Суффиксы размеров `k`, `m`, `g`.
- Ненулевой код возврата при ошибке конфигурации.

**Критерии приёмки.**
1. Все ключи из docs/03 §8 поддержаны и имеют значения по умолчанию.
2. Некорректная конфигурация не запускает сервер и даёт понятную ошибку.
3. Проверка конфигурации не открывает сетевой порт.
4. Unit-тесты покрывают приоритет источников и разбор размеров.
5. Секреты не печатаются в журнал.
6. `protocol.maxChunkBytes` проверяется как не меньше 2 байт; значение 0 или 1 отвергается до запуска; значение по умолчанию `64k` не меняется (ADR-015).

**Проверка.** Unit-тесты, ручной запуск проверки на корректном и некорректном файле.

**Роли.** Исполнитель — дешёвый; контролёр — сильный.

**Вне области.** Реализация сетевого транспорта и протокола.

**Ограничения.** Набор ключей не расширять без ADR. Значения по умолчанию не должны менять наблюдаемое поведение известных клиентов.
