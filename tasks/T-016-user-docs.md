# T-016. Пользовательская документация

**Цель.** Подготовить документацию, по которой продукт можно установить, настроить и эксплуатировать.

**Зависит от.** T-015, D-04.

**Входы.** docs/02 §10, [docs/04](../docs/04-protocol-compatibility-specification.md), docs/07.

**Результаты.**
- Руководство установки и запуска.
- Описание конфигурации со всеми ключами и значениями по умолчанию.
- Справочник протокола и перечень известных отличий.
- Руководство эксплуатации: запуск, остановка, наблюдение, типовые сбои.
- Описание сборки и воспроизводимости.
- Документация на русском языке.
- Регламент жизненного цикла по п. 11 «е» Правил № 1236: поддержка, исправления, развитие, необходимый персонал и фактические ответственные по данным владельца. Это регламент продукта, не восстановление процесса octocode.

**Критерии приёмки.**
1. Все инструкции выполнены на чистом стенде.
2. Описание конфигурации совпадает с docs/03 §8.
3. Перечень известных отличий совпадает с docs/04 §9.
4. Нет ссылок на несуществующие файлы и разделы.

**Проверка.** Проход по документации на чистом стенде, проверка ссылок.

**Роли.** Исполнитель — дешёвый; контролёр — сильный.

**Вне области.** Реестровое досье.

**Ограничения.** Документация описывает фактическую версию, а не желаемую.
