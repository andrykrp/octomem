# T-010. Срок жизни и вытеснение

**Цель.** Реализовать ленивое и активное удаление просроченных записей и вытеснение по LRU.

**Зависит от.** T-009.

**Входы.** ЧТЗ-04.

**Результаты.**
- Ленивая проверка срока при обращении.
- Фоновый поток очистки с периодом `expiry.reclaimIntervalSeconds`.
- Вытеснение по LRU по классам размеров.
- Счётчики `reclaimed`, `expired_unfetched`, `evicted_unfetched`.
- Поддержка `flush_all` с задержкой и без.

**Критерии приёмки.**
1. Просроченная запись никогда не возвращается клиенту.
2. Память под просроченными и удалёнными записями освобождается.
3. При нехватке памяти вытесняются давно неиспользуемые записи.
4. Фоновые потоки не блокируют обработку соединений.
5. Проверки времени идут только через `Clock`.

**Проверка задачи.** Unit-тесты времени и LRU. **Трассировка к релизу.** [TEST-01](../tests/TEST-01-unit.md), [TEST-04](../tests/TEST-04-functional.md), [TEST-09](../tests/TEST-09-fault-longrun.md).

**Роли.** Исполнитель — дешёвый; контролёр — сильный.

**Вне области.** Реализация движка и протокола.

**Ограничения.** Ошибка фонового потока не завершает процесс и пишется в журнал.
