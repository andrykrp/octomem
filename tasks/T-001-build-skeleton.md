# T-001. Каркас сборки и репозитория

**Цель.** Создать воспроизводимый каркас проекта octomem: сборку, структуру пакетов, правила зависимостей и базовые проверки.

**Зависит от.** Нет.

**Входы.** [docs/03](../docs/03-architecture-specification.md), [docs/07](../docs/07-security-operations-release.md), ЧТЗ-09.

**Результаты.**
- Сборка Maven с wrapper и зафиксированными версиями.
- Корневой пакет `ru.octomem` и подпакеты из docs/03 §3.
- Основной JAR с --release 25, сборка и проверка на OpenJDK 25; 21 только резерв, без Java 17, preview/incubator и внутренних API.
- Тест правил зависимостей пакетов.
- Зафиксированная временная метка сборки для воспроизводимости.
- Ноль обязательных runtime-зависимостей.
- Проверка runtime dependency tree и содержимого JAR: ноль сторонних Java/native-библиотек, build/test/benchmark-зависимости не упакованы. См. [платформу](../docs/java-platform.md).
- `compatibility-manifest.json` по docs/04 §10: точная версия и SHA-256 исходников эталона, обязательные команды, поля stats, целевой профиль платформ и известные отличия. Фиксируется до реализации подсистем; T-014 использует этот выбор при создании стенда.

**Критерии приёмки.**
1. `mvn verify` проходит на чистом стенде.
2. Сборка не требует сети при наличии локального кэша зависимостей.
3. Тест зависимостей падает при нарушении правил docs/03 §3.
4. Артефакт сборки — исполняемый JAR без внешних runtime-библиотек.
5. Повторная сборка даёт совпадающую полезную нагрузку либо различия объяснены.
6. Манифест совместимости не содержит `latest`, `to-be-*` и пустых обязательных списков; выбранные границы профиля согласованы с docs/04. Целевые платформы здесь не объявляются уже проверенными.

**Проверка.** Сборка, запуск теста зависимостей, повторная сборка, просмотр содержимого JAR.

**Роли.** Исполнитель — дешёвый; контролёр — сильный.

**Вне области.** Реализация подсистем, конфигурация, протокол.

**Ограничения.** Не добавлять обязательные runtime-зависимости. Не менять структуру пакетов без ADR. Maven — предварительное решение; замена сборки — отдельное решение ведущего.

## Статус приёмки (scoped, запись координатора)

**Принято scoped по исходным критериям 1–5.** Координатор принял T-001 ограниченно на основании текущих проверок зависимостей, точного манифеста источника и сборки на свободной от сторонних компонентов OpenJDK 25; финальная релизная готовность и платформенный PASS не заявляются. Архитектурный граф зафиксирован принятым [ADR-014](../docs/adr/ADR-014-package-dependency-edges.md) (R-07 закрыт); [ADR-013](../docs/adr/ADR-013-immutable-published-item-version.md)/[ADR-015](../docs/adr/ADR-015-chunk-sink-crlf-capacity.md) остаются PROPOSED, R-04/R-09 открыты, T-004 не заморожен.
