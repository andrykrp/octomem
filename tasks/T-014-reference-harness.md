# T-014. Стенд сравнения с эталоном

**Цель.** Подготовить воспроизводимый стенд для дифференциального сравнения octomem с зафиксированным эталонным Memcached.

**Зависит от.** T-001.

**Входы.** [docs/06](../docs/06-test-specifications.md), docs/04.

**Результаты.**
- Скрипты запуска эталона и octomem с одинаковыми настройками.
- Фиксация версии эталона, контрольной суммы, compile options.
- Генератор данных и сценариев с сохранением семян.
- Сравнение ответов, типов, кодов ошибок и состояния транзакций.

**Критерии приёмки.**
1. Обе реализации запускаются на одном стенде из скриптов.
2. Версия и хеши эталона зафиксированы в манифесте совместимости.
3. Сравнение воспроизводимо по семени.
4. Расхождения объясняются или заносятся в известные отличия.

**Проверка.** Пробный прогон на нескольких командах, просмотр манифеста.

**Роли.** Исполнитель — дешёвый; контролёр — сильный.

**Вне области.** Сами наборы испытаний находятся в `tests/`.

**Ограничения.** Эталон используется только как внешний оракул и не входит в поставку продукта.
