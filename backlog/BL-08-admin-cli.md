# BL-08. Административный CLI и управление

**Состояние.** Идея. В выпуск 1.0 не входит.

**Мотив.** Эксплуатации нужны удобные команды: статистика, сброс, изменение лимитов без перезапуска, проверка конфигурации.

**Что даёт.** Упрощение эксплуатации и снижение числа ошибок.

**Предпосылки.** Решение о разделении команд клиента и администратора; ограничения доступа.

**Влияние.** Новый интерфейс, возможно отдельный порт или сокет.

**Риски.** Расширение поверхности атаки; конфликт с сетевым протоколом.

**Решение.** Требуется задача с явным разделением публичного протокола и административного доступа.
