# BL-05. HTTP-метрики и health

**Состояние.** Идея. В выпуск 1.0 не входит.

**Мотив.** Системам мониторинга удобнее снимать метрики по HTTP, чем разбирать вывод `stats`. Также нужен простой признак готовности для оркестраторов.

**Что даёт.** Упрощение наблюдения и автоматического перезапуска.

**Предпосылки.** Отдельный порт или путь, не влияющий на основной протокол.

**Влияние.** Дополнительный слушатель, конфигурация, ограничения доступа.

**Риски.** Расширение поверхности атаки; необходимость защиты эндпойнта.

**Решение.** Требуется задача с ограничением: отдельный порт, выключено по умолчанию.
