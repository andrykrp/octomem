# BL-02. Бинарный протокол

**Состояние.** Идея. В выпуск 1.0 не входит (P3).

**Мотив.** Часть старых клиентов работает только по бинарному протоколу. Это может быть обязательным для отдельных заказчиков.

**Что даёт.** Совместимость с такими клиентами.

**Предпосылки.** Устойчивый текстовый профиль и свободный ресурс на второй кодек.

**Влияние.** Новый декодер и кодировщик; проверка на реальных клиентах.

**Риски.** Двойной протокол усложняет поддержку и тестирование; ценность ограничена.

**Решение.** Не планируется по умолчанию. Рассматривается только при конкретном требовании заказчика.
