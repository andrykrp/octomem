# ui: задачи интерфейса пользователя

Версия 0.1 от 14.09.2026.

**Каталог намеренно пуст.**

В выпуске 1.0 у octomem нет графического интерфейса: продукт управляется командной строкой и файлом конфигурации, а наблюдается через команду `stats`. Задачи, связанные с интерфейсом командной строки, находятся в `design/` (форма) и `tasks/` (реализация).

Каталог сохраняется, потому что структура проекта общая и переносится на другие проекты, где интерфейс может понадобиться. Отсутствие файлов здесь означает «в этом выпуске интерфейса нет», а не «забыли заполнить».

Если графический или веб-интерфейс будет добавлен в область выпуска, задачи оформляются как `UI-NN` по [правилам разработки](../docs/development.md), а интерфейсное решение фиксируется отдельным ADR в `docs/03`.
